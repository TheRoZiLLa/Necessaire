# Nécessaire

> **Think. Discuss. Remember.**  
> A lightweight, collaborative mock-test web application for study groups to run practice exams together before tests.

Built specifically for high-speed study sessions:
- **No account / No passwords**: Jump in with just a room code and nickname.
- **Import from AI**: Paste questions generated by ChatGPT, Claude, or Gemini in seconds.
- **Synchronized Realtime Loop**: Answer individually &rarr; Discuss in Discord &rarr; Change your answer &rarr; Reveal together &rarr; Advance to next.
- **Post-Exam Review**: Replay the hardest questions missed by your group.

---

## ⚡ Quick Start (Local Development)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> **Zero-Config Offline Mode**: If no Supabase credentials are provided, Nécessaire automatically falls back to an in-memory / `localStorage` store with browser `BroadcastChannel` synchronization. You can test multi-player rooms locally simply by opening two browser windows side-by-side!

## 🚀 Cloud Deployment (Vercel + Supabase)

### Step 1: Set up Supabase

1. Create a free project at [supabase.com](https://supabase.com).
2. Go to the **SQL Editor** in your Supabase project dashboard.
3. Copy the contents of [`supabase/schema.sql`](supabase/schema.sql) and run the script.  
   This creates:
   - `mocks` & `questions` tables
   - `rooms` table (with status machine & `review_question_ids`)
   - `players` table (with room code association & host flag)
   - `answers` table (tracking initial & final answers)
   - Row Level Security (RLS) policies and realtime publication replication.
4. Verify that Realtime is enabled for `rooms`, `players`, and `answers` under **Database &rarr; Replication**.

### Step 2: Deploy to Vercel

1. Push your repository to GitHub or GitLab.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your Nécessaire repository.
4. Under **Environment Variables**, add:
   - `NEXT_PUBLIC_SUPABASE_URL`: Your Supabase Project URL (`https://xyzcompany.supabase.co`)
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: Your Supabase Project `anon public` API key
5. Click **Deploy**.

## 📋 Input Format for AI Questions

Nécessaire parses standardized multiple-choice questions directly from text. You can generate questions using this prompt:

```text
Please generate multiple-choice questions in this format:

1. [Question text here]
   A. [Option A]
   B. [Option B]
   C. [Option C]
   D. [Option D]
   Answer: [A/B/C/D]
   Explanation: [Brief explanation why this option is correct]

2. [Next question]
...
```

The parser automatically detects questions, extracts options A–D, verifies answers, validates explanations, and provides an inline editor before importing.

## 🔄 The 5-Phase Exam Loop

1. **Answer Phase**: Each participant selects their choice and clicks `[ Lock Answer ]`. Answers remain private; only the count of completed answers is broadcast.
2. **Discussion Phase**: Activated when all participants lock in. Displays *"Discuss your answers in Discord"*. Participants click `[ I'm Ready ]` when finished talking.
3. **Change Phase**: Players can stick with their initial answer or switch their choice before hitting `[ Final Lock ]`.
4. **Reveal Phase**: The host reveals the correct answer. Everyone sees the explanation, accuracy percentage, and who changed their answer.
5. **Next / Finish**: The host advances to the next question. At the final question, clicking `[ Finish Mock ]` displays the group accuracy summary and the top 5 questions needing review.

## 🛡️ Architecture & Boundaries

Nécessaire is deliberately kept lean:
- **No authentication / profiles / XP / leaderboards**
- **No in-app chat or voice** (use Discord for discussion)
- **Zero answer leakage**: The correct answer and explanation are never sent to non-host clients prior to the Reveal phase.
- **Mobile-friendly**: Optimized thumb targets (`min-h-[58px]`) and responsive viewports for iPhone and Android.
